# 🎙️ Python Voice Assistant

A Python-based JARVIS-style voice assistant that performs tasks using voice commands.

### Features

* 🎤 Speech recognition
* 🔊 Text-to-speech
* 🔎 Google Search
* 🎵 YouTube music
* 📝 Task management
* 💻 Application launcher
* 📱 WhatsApp messaging
* 🤖 AI queries
* 🎨 AI image generation

### Tech Stack

**Python | SpeechRecognition | pyttsx3 | PyAutoGUI | PyWhatKit | Mistral AI**

### Image Generation

The image-generation feature uses the **image generation API connected through the custom `image_form.py` module**.

### Run

```bash
pip install pyttsx3 SpeechRecognition PyAutoGUI plyer wikipedia pywhatkit
python main.py
```
